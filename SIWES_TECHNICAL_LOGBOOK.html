Work done included unboxing and inspecting 5 Dell Latitude 5440 laptops, configuring UEFI BIOS settings (Secure Boot, TPM 2.0, battery management), performing clean Windows 11 Enterprise installation over GPT partition tables, executing automated staging via Windows Configuration Designer provisioning packages (.ppkg) that injected Wi-Fi profiles, root certificates, and OEM drivers, deploying the enterprise application stack (Microsoft 365, Zscaler VPN, CrowdStrike Falcon), joining devices to the `cwg.local` Active Directory domain, escrowing BitLocker keys to AD, and completing employee handover.
